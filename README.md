# MoPlayer - 一体化桌面播放器

## 项目简介

MoPlayer 是一个基于 Tauri + React 构建的现代化桌面音视频播放器，采用一体化设计，类似于 PotPlayer 等传统播放器的界面风格。

## 主要特性

### 🎯 一体化界面设计
- **智能菜单栏**：自动隐藏式菜单栏（鼠标静止5秒后隐藏）
- **无分层窗口**：摒弃了原有的分层设计，提供统一的用户体验
- **专业外观**：深色主题，现代化 UI 设计
- **视频自适应**：视频自动缩放以适应窗口尺寸

### 🎮 完整的播放控制
- **播放控制**：播放/暂停、停止、快进/快退
- **音量控制**：音量调节、静音切换
- **进度控制**：拖拽式进度条，精确定位
- **自动隐藏控制栏**：播放时自动隐藏，鼠标移动时显示

### ⌨️ 键盘快捷键支持
- `Space` - 播放/暂停
- `↑/↓` - 音量调节
- `M` - 静音切换
- `Ctrl + ←/→` - 快退/快进 (10秒)
- `F11` - 全屏切换
- `Ctrl + O` - 打开文件

### 📁 文件支持
- **多格式支持**：MP4, WebM, OGV, MP3, WAV, OGG
- **拖拽加载**：支持文件拖拽到播放器
- **文件选择**：通过菜单或快捷键打开文件

### 🎮 智能交互
- **自动隐藏菜单**：鼠标静止5秒后自动隐藏菜单栏
- **视频自适应**：窗口尺寸变化时视频自动缩放适配
- **毛玻璃效果**：菜单栏采用半透明毛玻璃设计
- **快捷键支持**：完整的键盘快捷键操作

## 技术架构

- **前端框架**：React 18 + TypeScript
- **桌面框架**：Tauri 2.0
- **样式方案**：Tailwind CSS
- **构建工具**：Vite
- **后端语言**：Rust

## 窗口配置

- **默认尺寸**：1120 x 630 像素
- **最小尺寸**：480 x 320 像素
- **响应式设计**：支持任意尺寸调节
- **居中显示**：启动时自动居中

## 环境要求

- **Node.js**：版本 16 或更高
- **Rust**：最新稳定版本
- **Tauri CLI**：用于构建和开发

## 安装步骤

### 1. 安装 Rust
如果还没有安装 Rust，请访问 [https://rustup.rs/](https://rustup.rs/) 或运行：
```bash
# Windows
winget install Rustlang.Rustup

# 或者下载安装程序
# https://forge.rust-lang.org/infra/channel-layout.html#the-forge
```

### 2. 安装 Tauri CLI
```bash
# 全局安装 Tauri CLI
npm install -g @tauri-apps/cli

# 或者使用 cargo 安装
cargo install tauri-cli
```

### 3. 验证安装
```bash
# 检查 Tauri CLI 是否安装成功
tauri --version

# 检查 Rust 是否安装成功
rustc --version
```

## 开发运行

在项目根目录（`moplayer-R/`）下运行以下命令：

```bash
# 1. 安装项目依赖
npm install

# 2. 开发模式运行
npm run tauri dev
# 或者直接使用 tauri 命令
tauri dev

# 3. 构建应用
npm run tauri build
# 或者直接使用 tauri 命令
tauri build
```

## 故障排除

### 如果提示 'tauri' 不是内部或外部命令：
1. 确保已安装 Tauri CLI：`npm install -g @tauri-apps/cli`
2. 重启命令行窗口
3. 检查环境变量是否正确设置
4. 或者使用 `npx @tauri-apps/cli dev` 代替 `tauri dev`

### 如果 Rust 相关错误：
1. 确保已安装 Rust：访问 [https://rustup.rs/](https://rustup.rs/)
2. 更新 Rust：`rustup update`
3. 添加必要的组件：`rustup target add x86_64-pc-windows-msvc`

**注意**：所有命令都需要在项目根目录下执行，即包含 `package.json` 和 `src-tauri/` 文件夹的目录。

## 主要改进

相比原有的分层设计，新的一体化播放器具有以下改进：

1. **统一的用户界面**：消除了窗口分层，提供一致的用户体验
2. **专业的播放器外观**：采用传统播放器的布局和交互模式
3. **完整的功能集成**：菜单、播放控制、状态显示完全集成
4. **优化的交互体验**：键盘快捷键、自动隐藏控制栏等
5. **现代化的视觉设计**：渐变背景、动画效果、自定义样式

## 使用说明

1. **打开文件**：
   - 使用菜单栏 "文件" → "打开文件"
   - 使用快捷键 `Ctrl + O`
   - 直接拖拽文件到播放器

2. **播放控制**：
   - 点击播放/暂停按钮或按 `Space`
   - 拖拽进度条调整播放位置
   - 使用 `Ctrl + ←/→` 快退/快进

3. **音量控制**：
   - 拖拽音量滑块调节音量
   - 使用 `↑/↓` 键调节音量
   - 按 `M` 键切换静音

4. **全屏播放**：
   - 使用菜单栏 "视图" → "全屏"
   - 按 `F11` 键切换全屏
