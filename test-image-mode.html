图片模式功能测试

已实现功能

  • 加载图片时保持窗口尺寸不变
  • 图片适应窗口，完全显示在中央

待测试功能

  • 滚轮缩放功能
  • 窗口自动适应图片尺寸
  • 缩放极限控制（图片最大10倍，最小5%）
  • 窗口缩放极限控制（长边最小200像素）
  • 同目录图片切换功能
  • 左右方向键切换图片
  • 窗口尺寸锁定功能
  • 空格键+拖拽移动图片

测试说明

请在MoPlayer应用中测试以下功能：

  1. 打开一张图片文件
  2. 使用鼠标滚轮测试缩放功能
  3. 双击窗口测试锁定/解锁功能
  4. 按住空格键拖拽图片
  5. 点击窗口左右边缘10%区域切换图片
  6. 使用左右方向键切换图片

预期行为：

  • 窗口未锁定时：滚轮缩放会同时调整窗口大小
  • 窗口锁定时：滚轮只缩放图片，窗口大小不变
  • 缩放达到极限时应有视觉反馈
  • 图片切换应平滑，状态指示器应更新

技术实现要点

  • 使用Tauri API进行窗口大小控制
  • CSS transform实现图片缩放和移动
  • 键盘事件监听实现快捷键功能
  • 文件系统API实现同目录图片列表获取
  • 状态管理确保各功能协调工作
